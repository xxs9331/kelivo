# Kelivo 手机与 DSH / DS Bot 续聊测试

目标：两端的用户消息和助手回复进入同一同步会话。你主动发送下一条消息时，
该端模型带上同步后的历史继续回答。同步不会唤醒 Bot、运行模型、调用工具或执行远程操作。

## 配对和续聊

1. 服务部署到手机与电脑均能访问的 HTTPS 地址。WSL 当前的 `127.0.0.1:8787` 只用于本机调试，
   手机不能直接使用这个地址。远程部署需要服务器地址、SSH 用户、端口、密钥文件路径，
   以及可解析到该服务器的域名；不要把私钥内容写进仓库。
2. 服务器生成一个配对码，在 DSH「Bot 设置 → Kelivo 同步」填写服务器地址和配对码。
   再生成另一个码，在 Kelivo「设置 → 多设备同步」配对相同服务器。
   配对码一次有效，五分钟过期。
3. 电脑已有聊天：在 DSH 同步设置中选择「同步一个 Bot 的对话」。手机同步后可看到对应会话。
   使用手机上已配置好的助手与模型，在这条会话中发送下一条消息。
4. 手机已有聊天：先在两端执行同步，DSH 选择「导入手机对话」。它会创建一个新 Bot，
   保留用户消息和助手回复。选择该 Bot 的模型，再由你主动发消息继续聊。
5. 两端程序运行时周期同步，也可点击「立即同步」。切换设备前后先手动同步一次，
   确认最近消息已到达。安卓程序被系统关闭后不会在后台持续同步。

## 当前范围

同步 Bot 私聊和 Kelivo 会话的文字历史；模型、API 密钥、系统提示、权限、群聊、记忆和附件文件由各端独立管理。
两个端可以使用不同模型，因此回答风格可以不同。

手机编辑消息后更新 DSH 的模型上下文，DSH 保留原始审计记录；修改已压缩或归档的历史，
会在当前上下文追加明确的修正说明。手机删除会话会停止这条关联的同步，并保留电脑 Bot；
删除电脑 Bot 会删除对应的手机会话。同步服务当前以明文存储正文，没有端到端加密。
